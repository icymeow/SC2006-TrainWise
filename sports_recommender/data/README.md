# Data Files

This directory contains the data files used by the Sports Activity Recommender system:

1. `Cleaned_Activities_Data.csv` - Contains information about sports facilities and activities:
   - Facility names
   - Activity types
   - Location information (latitude, longitude)
   - Indoor/outdoor status
   - Available activities
   - Intensity levels

2. `24hourWeatherForecast.json` - Contains weather forecast data:
   - Temperature
   - Weather conditions
   - Air quality
   - Updated every 24 hours

These files are used to populate the database and provide real-time weather information for activity recommendations.
